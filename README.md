# 局域网文件传输助手（LanFileHub）

## 项目简介

LanFileHub 是一个部署在局域网环境下的文件传输与管理平台，提供安全、高效、便捷的文件处理能力。

## 核心功能

### 1. 用户与权限管理
- 支持超级管理员和普通用户角色
- 超级管理员可增删改查用户账号，分配存储空间配额
- 普通用户可管理个人空间，设置文件共享权限

### 2. 文件管理
- 文件暂存：支持上传临时文件，可设置保留时间
- 个人空间：按用户名隔离目录，支持文件夹层级
- 在线预览：支持图片、PDF、文本、音视频
- 在线编辑：支持 Office 文档在线编辑（集成 OnlyOffice）

### 3. 娱乐共享模块
- 音乐：上传 mp3/flac 等格式，支持网页端播放、创建歌单
- 影视：上传 mp4/mkv 等格式，支持网页端流式播放、进度记忆

### 4. 即时通讯
- 支持局域网内用户发送文本消息
- 支持发送小文件
- 显示用户在线状态

### 5. 增强功能
- 自动备份功能
- 文件去重
- 局域网广播消息
- 系统通知

## 技术栈

- **后端**：FastAPI (Python 3.9+)
- **前端**：Vue 3
- **数据库**：SQLite
- **实时通信**：WebSocket
- **文件存储**：本地磁盘

## 快速开始

### 系统要求
- Python 3.9 或 3.10
- Node.js 16+
- 支持 Windows 10/11、Linux（Ubuntu/CentOS）

### 部署步骤

#### Linux 系统
1. 克隆项目到本地
2. 在项目根目录执行：
   ```bash
   ./deploy/deploy_linux.sh
   ```

#### Windows 系统
1. 克隆项目到本地
2. 在项目根目录执行：
   ```cmd
   deploy\deploy_windows.bat
   ```

### 访问方式
- **系统主页**：http://localhost:8000
- **API 文档**：http://localhost:8000/docs
- **默认管理员账号**：
  - 用户名：admin
  - 密码：admin123


## 性能与安全

- **性能**：支持至少 100 并发用户，大文件上传速度可达局域网带宽上限的 80%
- **安全**：实现了 JWT 认证、权限控制、文件类型限制等安全措施
- **可靠性**：系统稳定运行时间不低于 99.9%

## 注意事项

- 本项目仅适用于局域网环境，不支持公网访问
- 建议使用 Python 3.9 或 3.10 版本，避免兼容性问题
- 首次部署时会自动创建管理员账号，请及时修改默认密码
- Office 在线编辑需要 OnlyOffice Document Server 支持
