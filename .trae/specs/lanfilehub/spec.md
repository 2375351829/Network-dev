# 局域网文件传输助手（LanFileHub）- 产品需求文档

## 概述
- **摘要**：开发一个部署在局域网环境下的文件传输与管理平台，支持文件暂存、用户空间管理、文件在线预览与编辑、多媒体娱乐共享、点对点聊天等功能。
- **目的**：解决局域网内文件传输、共享和管理的需求，提供安全、高效、便捷的文件处理能力。
- **目标用户**：局域网内的企业员工、家庭用户、小团队成员。

## 目标
- 提供安全可靠的局域网文件传输与管理功能
- 支持用户空间隔离与权限管理
- 实现文件在线预览与编辑能力
- 提供多媒体娱乐内容共享功能
- 集成即时通讯能力
- 支持跨平台部署与访问

## 非目标（范围外）
- 不支持公网访问
- 不提供云存储集成
- 不支持复杂的工作流审批
- 不包含高级数据分析功能
- 不支持大规模企业级部署（超过1000用户）

## 背景与上下文
- 局域网环境下，传统文件共享方式（如共享文件夹）缺乏权限控制、在线编辑能力和即时通讯功能
- 现有解决方案要么功能单一，要么部署复杂，不适合小型团队或家庭使用
- 随着远程办公和移动设备的普及，对局域网内文件管理的需求日益增长

## 功能需求
- **FR-1**：用户与权限管理
  - 支持超级管理员和普通用户角色
  - 超级管理员可增删改查用户账号
  - 超级管理员可分配用户存储空间配额
  - 超级管理员可预览所有用户文件
  - 超级管理员可设置全局共享策略
  - 普通用户可管理个人空间
  - 普通用户可共享文件/文件夹给不同级别
  - 普通用户可设置共享权限

- **FR-2**：文件管理
  - 支持文件暂存，可设置保留时间
  - 支持个人空间，按用户名隔离目录
  - 支持文件夹层级管理
  - 支持文件在线预览（图片、PDF、文本、音视频）
  - 支持 Office 文档在线编辑
  - 支持文件上传、下载、删除、重命名

- **FR-3**：娱乐共享模块
  - 支持音乐上传与网页端播放
  - 支持创建和共享歌单
  - 支持视频上传与网页端流式播放
  - 支持视频进度记忆
  - 支持字幕上传
  - 娱乐内容遵循共享权限设置

- **FR-4**：即时通讯
  - 支持局域网内用户发送文本消息
  - 支持发送小文件
  - 显示用户在线状态
  - 聊天记录可选存于 SQLite
  - 支持聊天历史搜索

- **FR-5**：增强功能（额外建议）
  - 自动备份功能
  - 文件去重
  - 局域网广播消息
  - 文件版本控制
  - 大文件分片上传/断点续传
  - 系统通知

## 非功能需求
- **NFR-1**：性能
  - 支持至少 100 并发用户
  - 大文件上传速度应达到局域网带宽上限的 80%
  - 页面加载时间不超过 2 秒

- **NFR-2**：安全性
  - 防止越权访问
  - 上传文件类型限制
  - 可选的病毒扫描
  - 数据传输加密

- **NFR-3**：可靠性
  - 系统稳定运行时间不低于 99.9%
  - 数据备份机制
  - 错误处理与恢复

- **NFR-4**：可用性
  - 支持 Windows 10/11、Linux（Ubuntu/CentOS）一键启动或命令行运行
  - 响应式 Web 界面，支持 PC/移动端浏览器
  - 清晰的错误提示

- **NFR-5**：可扩展性
  - 模块化设计，便于功能扩展
  - 支持未来可能的数据库迁移（如 PostgreSQL）

## 约束
- **技术**：
  - 数据库：SQLite
  - 数据交互：RESTful API + JSON
  - 实时通信：WebSocket
  - 后端：Python（FastAPI）或 Node.js（Express）
  - 前端：Vue 3 或 React
  - 文件存储：本地磁盘

- **业务**：
  - 部署环境为局域网
  - 预算有限，优先考虑开源解决方案

- **依赖**：
  - Office 在线编辑可能需要集成 OnlyOffice/Collabora
  - 多媒体播放依赖浏览器支持

## 假设
- 局域网环境稳定，网络带宽充足
- 用户数量在 100 以内
- 存储容量足以满足用户需求
- 部署环境具备基本的硬件资源

## 验收标准

### AC-1：用户管理
- **给定**：系统已部署，超级管理员登录
- **当**：超级管理员创建新用户并分配存储空间
- **那么**：新用户可使用分配的空间，且存储空间限制生效
- **验证**：`programmatic`

### AC-2：文件上传与管理
- **给定**：普通用户登录系统
- **当**：用户上传文件到个人空间并进行管理操作
- **那么**：文件成功上传，管理操作生效，空间使用情况更新
- **验证**：`programmatic`

### AC-3：文件共享
- **给定**：用户拥有文件权限
- **当**：用户设置文件共享给不同级别
- **那么**：被共享用户可按照权限访问文件
- **验证**：`programmatic`

### AC-4：在线预览与编辑
- **给定**：用户访问支持预览/编辑的文件
- **当**：用户点击预览/编辑按钮
- **那么**：文件在浏览器中正确显示/可编辑
- **验证**：`human-judgment`

### AC-5：娱乐模块
- **给定**：用户上传音乐/视频文件
- **当**：用户在网页端播放媒体文件
- **那么**：媒体文件正常播放，进度正确记录
- **验证**：`human-judgment`

### AC-6：即时通讯
- **给定**：两个用户在线
- **当**：一个用户向另一个用户发送消息
- **那么**：接收方实时收到消息，消息记录正确保存
- **验证**：`programmatic`

### AC-7：系统部署
- **给定**：目标环境满足基本要求
- **当**：执行部署步骤
- **那么**：系统成功启动并可访问
- **验证**：`programmatic`
